# アンデッド従者システム仕様書

## 概要

アンデッド従者は、死体と魂を使った儀式で蘇らせる恒久的な従者である。
通常のペットとは別枠で管理され、死霊術向けの専用運用を前提としている。

最終確認: 2026-03-29

## 紹介ページ向け要約

- アンデッド従者はペット枠を使わない
- 通常ペットとは管理方式が異なる
- その代わり、通常ペットと同じ挙動をするわけではない

## アンデッド従者とペットの違い

| 項目 | アンデッド従者 | 通常ペット |
|---|---|---|
| 加入方法 | 儀式で蘇生する | 勧誘・加入イベント・通常の仲間化 |
| ペット枠消費 | しない | する |
| 所属の扱い | 従者として管理される | 仲間/ペットとして管理される |
| パーティ一覧ウィジェット表示 | 通常のパーティ一覧ウィジェットには出ない | 通常のパーティ一覧ウィジェットに出る |
| 仲間上限の表示 | 通常の仲間数/最大 ally 表示には含まれない | 通常の仲間数/最大 ally 表示に含まれる |
| 追従方式 | 従者専用の追従処理でついてくる | 通常のパーティ追従 |
| 通常の仲間加入 | 不可 | 可能 |
| 肉切り包丁での屠殺 | 不可。従者UIの解放を使う | 通常ルールに従う |
| 繋ぎ柱・通常騎乗導線 | 基本的に対象外 | 対象になる |
| 日常行動 | 本を読む、共有コンテナから物を取る、PCと一緒に釣るなどの一部「通常仲間向け」行動は行わない | こうした通常仲間向け行動を行うことがある |
| 専用蘇生 | 死亡後も従者として保持され、還生・再展開の対象になる | 通常の仲間/ペットの復帰ルールに従う |
| 召喚系能力 | 現在の仕様では使えない | 通常は使える |
| 退避中の扱い | 既定では停止。ModOptionで拠点内の移動・仕事・戦闘を許可できる | 通常ルールに従う |

## 補足

- アンデッド従者は「ペットの上位互換」ではなく、別ルールのユニット。
- 特に、ボスや特殊個体を従者化しても、元の挙動を完全再現するわけではない。
- 召喚系能力を持つ個体でも、従者化後はその能力を使えない場合がある。

## 退避と拠点常駐

- `退避` は従者をホームへ戻し、プレイヤー追従中の戦闘従者一覧から外す既存状態。
- ModOption `退避中も拠点貢献` が `OFF` の間は、退避従者はその場で停止し、仕事も戦闘もしない。
- この ModOption を `ON` にすると、退避従者はホームゾーンで移動・仕事・戦闘を行う。
- ただし `ON` でも、退避従者はプレイヤーへ追従せず、従者呪文やアクティブ従者戦力の集計対象にもならない。
- 退避従者は引き続き `TraitUndeadServant` を持つため、ショップや通常住民向けの Trait 機能を復元するものではない。
- 従者は通常の住民掲示板や家畜掲示板に表示されるが、そこから管理操作はできない。
- 従者は banish の対象にならず、遠征掲示板からも派遣できない。
- 住民掲示板では、従者の仕事/趣味 tooltip と現在状態（`従者(戦闘)`、`従者(労働)`、`従者(退避)` など）だけ確認できる。
- 従者UIはホットキーで開閉できる。既定値は `Shift+N` で、ModOptions から変更可能。

## 紹介文の短文サンプル

> アンデッド従者は、通常のペットとは別枠で運用される恒久ユニットです。  
> ペット枠を消費しない代わりに、ロスター表示や一部の仲間向け挙動、召喚系能力などは通常ペットと同一ではありません。
