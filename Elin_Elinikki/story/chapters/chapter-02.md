## Outline

1. **入層** - 巨大な地下空洞。天井が見えない。仲間実体同行
   - 暗い。遠くに焚き火の残り火が点光源として見える
   - ソラ:「天井が……見えない。とんでもない規模だ」
   - ミナ:「足元見ろ。上向いてると落ちる」

2. **反響の気づき（段階1）** - 歩くと足音が異様に響く
   - 数秒後に足音が返ってくる
   - ソラ:「エコーのタイミング、距離と合わない」
   - ミナ:「洞窟なんだからエコーぐらいあるだろ」

3. **★反響実験（段階2）** - 特定地点Aに到達
   - トリガー: 地点Aに立つ → SE変化
   - ソラが手を叩く。3秒後に返る。もう一度叩く。今度は2秒
   - ソラ:「間隔が変わった。反射なら距離で決まるから同じタイミングのはずだ」
   - ミナ:「お前が動いたんだろ」
   - ソラ:「動いてない！ ……もう一回やる」

4. **★反響実験（段階3）** - 地点Bに移動
   - トリガー: 地点Bに立つ → SE変化
   - ソラ:「場所を変える。科学的にやろう」
   - 手を3回叩く。3秒後に3回返る
   - ソラ:「回数まで合ってる」
   - ミナ:「反射で回数が保存されるのは……」
   - ソラ:「ありえなくはない。だがもう一つ試す」
   - ミナ:「……好きにしろ」（反論を諦め始めている）

5. **★反響実験（段階4）── PHMクライマックス** - 地点Cに移動
   - トリガー: 地点Cに立つ → SE変化
   - ソラが2回叩く。間を置く。3回叩く
   - 3秒 ── 2回返る。間。3回返る。パターンが完全に再現される
   - ソラ:「パターンを送ったら……パターンが返ってきた」
   - ソラ:「これは反射じゃない。応答だ。何かがこちらを認識して返事をしている」
   - ミナ:「……」（数秒黙る）
   - ソラ:「ミナ。聞いたよな？」
   - ミナ:「……聞いた」（小さい声）
   - ソラ:「ここに何かいる。知性がある。伝えようとしてる」
   - → フラグ: `chitsii.elinikki.quest.event.trace_echo = 1`

6. **探索区間** - 広い空洞を歩く。余韻の会話
   - ソラ:「壁の記号、水路、石の配置、そしてこの応答。全部つながる」
   - ソラ:「このネフィアには知性がある」
   - ミナ:「……」（否定しない。初めて否定しない）
   - ソラ:「ユウの手帳の『伝わった』。ユウもこれを体験したんだ」

7. **痕跡7: 床の地図** ★新規
   - トリガー: 平らな岩を調べる
   - 線と記号で構成された図。通路、分岐、行き止まりが描かれている
   - ソラ:「地図じゃない。これは通信図だ。壁の記号と同じ体系で描かれてる」
   - ミナ:「これは人間が描いたんじゃないのか？ ユウの」
   - ソラ:「いや、壁の記号と同じ筆致だ。同じ存在が描いてる」
   - （実際は同じ人間＝ユウが描いたから同じ筆致。だがソラは「記号＝知性体」と信じ込んでいるので逆の結論を出す）
   - → フラグ: `chitsii.elinikki.quest.event.trace_map = 1`

8. **痕跡5: 壁の人影**
   - トリガー: 壁の黒い影を調べる
   - 人の形に焼きついた影。立ったまま消えたように見える
   - ソラ:「エーテル融解の痕跡だ。高濃度のエーテルに曝露されると、有機物の影が……」
   - ソラ:「これがユウの……？ いや、サイズが違う。もっと前からあるものかもしれない」
   - ミナ:「……こんなところに長くいたくない。先に行くぞ」
   - → フラグ: `chitsii.elinikki.quest.event.trace_shadow = 1`

9. **次層への通路**
   - ソラ:「奥から暖かい空気が来てる。生体の熱？」
   - ミナ:「地熱だろ。普通の」
   - ソラ:「……そうだな。たぶん」（だがもう、ミナの「普通の」が弱く聞こえる）
   - zone遷移: → 花の層
