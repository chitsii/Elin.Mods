# Plot Structure

## Story Structure

**Model:** Kishotenketsu (起承転結)

| Beat | Act | Description |
|------|-----|-------------|
| Ki (起) | 導入 | 依頼受諾、パーティ合流、ネフィア進入 |
| Sho (承) | 展開 | 3層の探索。痕跡発見→推理→確信の積み上げ |
| Ten (転) | 転換 | ユウ再会。「何もいないよ」。推理の全崩壊 |
| Ketsu (結) | 結末 | 帰還。答えの出ない問いを抱えて戻る |
