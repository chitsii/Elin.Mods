# Worldbuilding

## World Overview

Elinの世界をベースに、高エーテル濃度のネフィア内部で起きる知覚変容を軸にした物語空間。空間自体は自然の洞窟だが、エーテルの影響で人間の知覚が歪み、「異様な美しさ」として認識される。ユウの生活痕跡がその上に重なり、「知性体の痕跡」に誤読される。
