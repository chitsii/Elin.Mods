## Description

### 見た目（プレイヤーの知覚）

洞窟内に広がる花畑。あり得ない。岩の間から発光する花が無数に咲いている。空気が甘く、暖かい。色は橙と紫が主調。Elin のどの場所とも似ていない。夢の中にいるような感覚。

### 実際

ユウが食料の残滓（干し果物の種、野菜くず）を捨てていた場所。エーテル高濃度環境で植物がありえない速度で変異・成長した。発光はエーテル変異の副産物。美しいが、根元はゴミ捨て場。

## Notable Features

### 花畑の3段階構成 ★拡張

花の層を「一枚の花畑」ではなく、3つの区画に分ける。

#### 区画1: 入口の薄闇（トンネルから出た直後）

- まだ暗い。だが足元に小さな発光する花がぽつぽつと見える
- ここでは会話なし。歩くだけ
- 花が足元にだけ見えるのが、「何かが始まる」予感を作る

#### 区画2: 満開の広場 ★ゆめにっきのピーク

- 一気に視界が開ける。一面の発光する花畑
- **30秒〜1分の無言区間**。BGMだけ。歩かせる
- 遅延トリガー: 中央付近で仲間の会話が発火
  - ソラ:「……これは……」（珍しく言葉に詰まる）
  - ミナ:「……」
  - ミナ:「……綺麗だな」（一度だけ。すぐ黙る）
- ここでプレイヤーが自由に歩き回れる時間を設ける

#### 区画3: 奥の根元（花の源泉）

- 花が最も密集している場所。だが近づくと、根元の様子が見えてくる
- 朽ちた有機物、果物の皮、魚の骨のようなものが花の隙間に見える
- ソラ:「有機物を基質にして……いや、これは苗床だ。何かがここに有機物を集めて、花を育てている」
- ミナ:「ゴミに見えるが」
- ソラ:「ゴミを使って生命を創造するなら、それこそ知性だろう」

### 痕跡4: 花畑の中心

- **トリガー**: 区画3の特定地点を調べる
- ソラ:「生命の創造だ。エーテルだけじゃこうはならない。意思がなければ、こんなものは生まれない」
- → フラグ: `chitsii.elinikki.quest.event.trace_flowers = 1`

### 痕跡8: 編み物 ★新規

- **見た目**: 花畑の端に、植物の繊維で編まれた紐のようなものが落ちている。規則的な編み目
- **ソラの推理**: 「道具だ。紐を編む知性。この空間の主は、手を使える存在だ」
- **真相**: ユウが暇すぎて植物の繊維を編んでいた。ロープを作ろうとしたが途中でやめた。「ロープ作ろうと思ったけど、何に使うか思いつかなくて」
- **トリガー**: 紐を調べる → drama会話
- → フラグ: `chitsii.elinikki.quest.event.trace_weave = 1`

### ゴミ捨て場（再訪エンドで見える）

- 花畑の区画3が実はゴミ捨て場
- 探索中は花に隠れてよく分からない（知覚変容で花が大きく見えている）
- 再訪エンドでは演出が控えめになり、ゴミの正体がもう少し見える

## Implementation

- マップ: `layer_bloom`
- 演出: 暖色LUT、発光エフェクト、甘い空気のBGM。3区画で段階的に強くなる
- 仲間: 演出同行（会話のみ）。一人で歩く体験を重視
- 調査点: 花畑中央（区画2遅延）、根元（区画3）、編み物 = 3箇所
- 無言区間: 区画2で30秒〜1分。演出の核心
