## Description

### 見た目（プレイヤーの知覚）

巨大な地下空洞。天井が見えないほど高い。声を出すと、数秒後に反響が返ってくる。だが反響のパターンが「ただのエコー」にしては規則的すぎるように聞こえる。壁の一部に、人の形に焼きついた影がある。

### 実際

自然の大空洞。音響特性でエコーが複雑に反射する。エーテルが音波を増幅し、遅延させるため、まるで「返事」のように聞こえる。壁の影はユウが長期間同じ場所で焚き火を焚いた煤の跡。

## Notable Features

### 痕跡3: 反響音 ★PHMクライマックス（段階的実験に拡張）

反響の発見は一回のトリガーではなく、**4段階の実験**で構成する。

#### 段階1: 気づき
- トリガー: 大空洞に入る（自動）
- 歩き始めると足音が異様に響く。数秒後に返ってくる
- ソラ:「エコーのタイミング、距離と合わない。エーテルが音を増幅してるのか？」
- ミナ:「洞窟なんだからエコーぐらいあるだろ」

#### 段階2: 最初の実験
- トリガー: 特定地点Aに立つ
- ソラが手を叩く。3秒後に返る。もう一度叩く。今度は2秒
- ソラ:「間隔が変わった。反射なら同じタイミングで返るはずだ」
- ミナ:「お前が動いたんだろ」
- ソラ:「動いてない！」

#### 段階3: 検証
- トリガー: 特定地点Bに移動して立つ
- ソラ:「場所を変えて試す。科学的にやろう」
- 手を3回叩く。3秒後に3回返る
- ソラ:「回数まで合ってる。反射で回数が保存されるのは……ありえなくはないが」
- ミナ:「ほら、説明がつくだろ」
- ソラ:「もう一つ試す」

#### 段階4: 確信 ★PHMの「通じた」瞬間
- トリガー: 特定地点Cに立つ
- ソラが2回叩く。間を置く。3回叩く
- 3秒後 ── 2回返る。間。3回返る。パターンが完全に再現される
- ソラ:「パターンを送ったら、パターンが返ってきた……！」
- ソラ:「これは反射じゃない！ 応答だ！ 何かがこちらを認識して返事をしている！」
- ミナ:「……」（否定の言葉が出ない。数秒黙る）
- ミナ:「……偶然だろ」
- ソラ:「ミナ、聞いたよな！？ 今の聞いたよな！？」
- ミナ:「……聞いた」（小さい声で）

### 痕跡7: 床に刻まれた地図 ★新規

- **見た目**: 大空洞の平らな岩の上に、線と記号で構成された図が刻まれている。通路、分岐、行き止まりのようなものが描かれている
- **ソラの推理**: 「地図じゃない。これは……通信図だ。壁の記号と同じ体系で、位置関係を示している。知性体がネフィア全体の構造を記録している」
- **真相**: ユウが出口を探すために描いた洞窟の地図。途中で諦めた。「描いてたんだけど、奥行きすぎてわけ分からなくなった」
- **トリガー**: 平らな岩を調べる → drama会話
- **ミナ/ソラの議論**:
  - ミナ:「これは人間が描いたんじゃないのか？ ユウの」
  - ソラ:「いや、壁の記号と同じ筆致だ。人間じゃない」（※実際は同じ人間＝ユウが描いたから同じ筆致なのだが、ソラは「記号 = 知性体」と思い込んでいるので逆の結論を出す）
  - ミナ:「……」

### 痕跡5: 壁の人影

- **見た目**: 壁に人の形が黒く焼きついている。立ったまま消えたように見える
- **ソラの推理**: 「エーテル融解の痕跡だ。高濃度のエーテルに曝露されると、有機物の影が残る。ここで誰かが……」
- **真相**: 焚き火の煤。長時間同じ場所で火を焚き続けたら壁に影が焼きついた
- **トリガー**: 壁を調べる → drama会話

## Implementation

- マップ: `layer_echo`
- 演出: 暗め、反響SE（地点A/B/Cそれぞれで異なるSEトリガー）、焚き火光源
- 仲間: 実体同行（広い空間）
- 調査点: 反響実験3地点 + 地図 + 人影 = 5箇所
- ミナの動揺: 反響の段階4でミナが初めて否定しきれない。これが2章の感情的クライマックス
