## Description

### 見た目（プレイヤーの知覚）

水と苔の洞窟。天井から水が滴り、壁面に青緑色の苔が広がる。光源は不明だが薄く青い光が充満している。水音が絶えず聞こえる。静かで、美しく、少し不安。

### 実際

自然の鍾乳洞。エーテル高濃度で苔が変異して発光している。水は地下水脈。「美しすぎる」のはエーテル知覚変容で色彩が増幅されているから。

## Notable Features

### 痕跡1: 壁の刻み目

- **見た目**: 壁面に規則的な記号が刻まれている。等間隔で、体系的に見える
- **ソラの推理**: 「記号体系だ。何かが通信しようとしている。最初の群は等間隔だが、途中から間隔が変わる。等比数列に近い」
- **真相**: ユウが正の字で日数を数えていた。50日目あたりで飽きて、暇つぶしに模様を描いた
- **トリガー**: 壁を調べる → drama会話
- **追加の調査**: 刻み目の近くに削りかす。ソラ:「新しい。最近のものだ」→ ユウがまだ生きている示唆

### 痕跡2: 石の配置

- **見た目**: 小部屋に石が整然と並んでいる。大きさと色で分類されているように見える
- **ソラの推理**: 「さっきの壁の記号と合わせて考えると……座標系だ。記号が軸、石が座標点。位置関係に意味がある」
- **真相**: 食料・水・道具の分類整理。散らかすと不安だったから
- **トリガー**: 小部屋に入る → 石を調べる → drama会話
- **ミナの反応**: 「……整理整頓にしては丁寧すぎないか？」（ミナも少し引っかかる最初の瞬間）

### 痕跡6: 水路の溝 ★新規

- **見た目**: 地面に浅い溝が走っている。水が溝に沿って流れ、奥の窪みに溜まっている
- **ソラの推理**: 「水を誘導している。自然の浸食ではありえない直線だ。知性体が環境を制御している証拠」
- **真相**: ユウが飲み水を確保するために石で溝を掘った。「水場まで歩くの面倒だったから、こっちに引いた」
- **トリガー**: 溝を調べる → drama会話
- **ミナ/ソラの議論**:
  - ソラ:「自然浸食なら曲がるはずだ。この角度は意図的」
  - ミナ:「たまたま岩の目に沿って流れただけだろ」
  - ソラ:「たまたまが多すぎるんだよ。壁の記号、石の配置、この水路。三つ揃って偶然か？」
  - ミナ:「……」（反論できない。だが納得もしていない）

### ユウの手帳

- 通路の脇に古い手帳が落ちている
- 最後のページに「伝わった」とだけ書いてある
- ソラ:「ユウの字だ。……『伝わった』？ 何が、誰に伝わったんだ？」
