## Description

### 見た目

ただの洞窟の一角。焚き火の跡。雑に敷かれた寝袋。積まれた荷物。壁に掛けられた水筒。乾燥中の干し肉。

演出が全て消える。fog なし。LUT なし。色調補正なし。BGM は環境音だけ。

### 意図

花の層までの幻想的な空間との落差が最大の演出。プレイヤーは「もっと深い何か」を期待しているが、ここにあるのはただの生活空間。ユウの数ヶ月間の「普通の暮らし」がそこにある。

## Notable Features

### ユウ

焚き火のそばに座っている。干し肉を齧っている。プレイヤーたちが来たことに驚くが、大げさではない。「お、来たのか」。

### 真相の会話

プレイヤーが各痕跡について質問できる（dialogFlags で制御）。ユウの回答は全て淡々。

質問順は自由。全部聞いても聞かなくてもいい。聞いた分だけ truth フラグが立つ。

### 帰還の提案

全ての会話が終わる（または打ち切る）と、ミナが「帰るぞ」と言う。ユウは素直についてくる。「出口知ってるなら最初から来てくれよ」。

## Implementation

- マップ: `yuu_camp`
- 演出: 一切なし。通常の洞窟。焚き火の光源のみ
- 仲間: 演出同行 → ユウと合流後、ユウが実体として加わる
- 会話: 痕跡ごとに個別の会話チェーン。trace フラグがある痕跡だけ質問可能
- 帰還トリガー: 出口へ向かう（zone遷移で入口マップへ）
